# Стальные Грозы — 2D танковые сражения

Браузерная игра в духе War Thunder (2D, вид сверху): Германия против СССР,
эпоха Второй мировой, модель повреждений, ИИ-союзники и противники, совместные
бои с авиацией.

## Запуск

Вариант 1 — просто открыть `index.html` в браузере (Chrome / Firefox / Edge).

Вариант 2 — локальный сервер:

```bash
cd steel-storms
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Возможное в игре

- **10 танков** — по 5 на страну: Pz. IV G, «Пантера», «Тигр», StuG III G, «Тигр II»;
  Т-34 (1941), Т-34-85, КВ-1, ИС-2, СУ-152.
- **Модель повреждений**: приведённая толщина брони по углу попадания, рикошеты,
  «не пробил», повреждения модулей (гусеница, двигатель, орудие, боеукладка с
  детонацией), потери экипажа, пожары с уроном по таймеру.
- **ИИ**: союзные и вражеские танки сами выбирают цели, держат дистанцию по классу,
  кружат, целятся с упреждением и учитывают пробитие.
- **Авиация**: у каждой стороны истребитель и бомбардировщик
  (Bf 109 / Ju 87 «Штука»; Ла-5 ФН / Ил-2). Пулемёты танков автоматически отстреливаются
  от самолётов, бомберы подлетают к целям и сбрасывают бомбы (осколочно-фугасный
  урон по площади).
- **Режим**: захват точки «А» + очки прочности. Победа — обнулить очки противника
  (фраги, удержание точки) или уничтожить всю его технику.
- Возрождение игрока через 8 секунд, миникарта, kill-фида, звуки на WebAudio
  (генерируются процедурно, без внешних файлов).

## Управление

| Клавиша | Действие |
|---|---|
| W / S | вперёд / назад |
| A / D | поворот корпуса |
| Мышь | наводка башни |
| ЛКМ | выстрел (автоповтор при удержании) |
| — | пулемёт по самолётам стреляет автоматически |

## Структура

```
index.html        — разметка, HUD, меню
css/style.css     — стили интерфейса
js/utils.js       — математика
js/audio.js       — процедурный звук (WebAudio)
js/data.js        — ТТХ танков и самолётов
js/entities.js    — танк, снаряд, бомба, самолёт, частицы, модель повреждений
js/ai.js          — ИИ танков и самолётов
js/ui.js          — меню выбора танка, HUD
js/main.js        — игровой цикл, бой, захват, волны авиации, рендер
test/harness.js   — headless смоук-тест (node test/harness.js)
```

## Баланс и настройка

Все ТТХ — в `js/data.js` (броня, пробитие, урон, перезарядка, скорость).
Параметры боя (очки прочности, радиус/скорость захвата, интервал волн авиации) —
в начале `js/main.js` (`G.startTickets`, `updateCapture`, `updateWaves`).
